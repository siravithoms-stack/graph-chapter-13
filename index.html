13. การจัดการโครงการ (PERT System)

ผู้สอน: รศ.กวี หวังนิเวศน์กุล
Program Evaluation & Review Technique

ระบบเพิร์ท (PERT System) กับการจัดการความไม่แน่นอน

แตกต่างจากระบบ CPM ที่กำหนดเวลาแน่นอนเพียงค่าเดียว PERT ใช้หลักสถิติและทฤษฎีความน่าจะเป็น เข้ามาช่วยประเมินระยะเวลาทำงานภายใต้ความเสี่ยง โดยอาศัยค่าประมาณเวลา 3 ค่า ($a, m, b$)

CPM

ระบบ CPM (Critical Path Method)

Determinism Model

  • กำหนดช่วงเวลาทำงานเพียง ตัวเดียว
  • ใช้ประสบการณ์และความชำนาญที่เคยทำมา
  • เหมาะกับงานประจำที่ทราบระยะเวลาแน่นอนอยู่แล้ว
PERT

ระบบ PERT (Program Evaluation & Review)

Probabilistic Model

  • กำหนดเวลาเป็น 3 ค่า เพื่อรองรับความเสี่ยง
  • เหมาะกับงานใหม่ งานวิจัย หรือโครงการก่อสร้างที่ไม่เคยทำมาก่อน
  • คำนวณหาโอกาส (%) ที่โครงการจะเสร็จทันตามเป้าหมาย

ค่าประมาณเวลารายกิจกรรม 3 ค่า ($a, m, b$)

Optimistic Time ($a$) ขั้นต่ำ

ค่าเวลาต่ำที่สุดที่คิดว่าจะทำงานให้เสร็จได้ ถ้าทุกอย่างเป็นไปได้ด้วยดี สภาพแวดล้อมราบรื่นที่สุด

Most Likely Time ($m$) ปกติ

ค่าเวลากลางๆ ที่มีโอกาสเกิดมากที่สุดในการทำงานตามปกติภายใต้สภาวะทั่วไป

Pessimistic Time ($b$) สูงสุด

ค่าเวลามากที่สุดที่คิดว่าจะทำงานเสร็จ หากเกิดอุปสรรค เลวร้าย หรือมีปัญหาติดขัด

สูตรคำนวณหลักในระบบ PERT

1. เวลาเฉลี่ยที่ควรจะเป็น (Expected Time)
$$T_e = \frac{a + 4m + b}{6}$$

การถ่วงน้ำหนักตามการกระจายแบบ Beta Distribution ให้ความสำคัญกับ $m$ ถึง 4 เท่า

2. ค่าเบี่ยงเบนมาตรฐานกิจกรรม (Standard Deviation)
$$\sigma = \frac{b - a}{6}$$

วัดระดับความแน่นอน/ความเสี่ยง หาก $b - a$ มาก แสดงว่าความเบี่ยงเบนสูง

3. ค่าความแปรปรวนกิจกรรม (Variance)
$$V = \sigma^2 = \left(\frac{b - a}{6}\right)^2$$

ค่านำไปยกกำลังสองเพื่อไม่ให้ติดลบ สะสมเฉพาะกิจกรรมบน สายงานวิกฤต

4. ความเบี่ยงเบนมาตรฐานโครงการ ($\sigma_{Te}$)
$$\sigma_{Te} = \sqrt{\sum V_{\text{critical}}}$$

ข้อควรระวัง: นำเฉพาะ Variance ของกิจกรรมบน สายงานวิกฤตหลัก มารวมกัน

5. การแปลงค่าเพื่อหาความน่าจะเป็น (Z-Score) Standard Normal Curve
$$Z = \frac{T_s - T_e}{\sigma_{Te}}$$
Z: ค่าความเบี่ยงเบนมาตรฐาน
Ts: กำหนดเวลาเป้าหมาย
Te: เวลารวมสายงานวิกฤต
σTe: SD รวมของโครงการ

กราฟการกระจายปกติ (Standard Normal Distribution Curve)

พื้นที่ใต้โค้งปกติแสดงถึง ความน่าจะเป็น (%) ที่โครงการจะทำงานได้เสร็จตามเป้าหมาย $T_s$

ช่วง Z ระหว่าง -1 ถึง +1
68%
ของโอกาสความสำเร็จ
ช่วง Z ระหว่าง -2 ถึง +2

ตัวอย่างประกอบการเรียน (Example 1 - 4)

ตัวอย่างการคำนวณตามบทเรียนการจัดการโครงการ PERT

Example 1 คำนวณหาค่าเวลาเฉลี่ย $T_e$

โจทย์: จงคำนวณหาค่าเวลาเฉลี่ยที่ควรจะเป็น ($T_e$) ของกิจกรรม K ซึ่งมีค่าระยะเวลา $a = 4, m = 5, b = 9$

วิธีทำ:
$$T_e = \frac{a + 4m + b}{6}$$
$$T_e = \frac{4 + (4 \times 5) + 9}{6} = \frac{33}{6}$$
$$T_e = 5.5 \text{ วัน} \approx 5.83 \text{ วัน}$$
Example 2 เปรียบเทียบค่าเบี่ยงเบนมาตรฐาน $\sigma$

โจทย์: งาน A มีระยะเวลา $(4, 5, 9)$ ส่วนงาน B มีระยะเวลา $(4, 7, 12)$ จงคำนวณหาค่าความเบี่ยงเบนมาตรฐาน

วิธีทำ: $$\sigma = \frac{b - a}{6}$$
$$\sigma_A = \frac{9 - 4}{6} = \frac{5}{6} = 0.83$$
$$\sigma_B = \frac{12 - 4}{6} = \frac{8}{6} = 1.33$$
สรุป: งาน A มีค่าเบี่ยงเบนต่ำกว่างาน B ($\sigma_A < \sigma_B$) แสดงว่างาน A มีความแน่นอนของช่วงเวลามากกว่างาน B

Example 4

คำนวณหาความน่าจะเป็นที่จะทำงานได้เสร็จทันเวลา (ต่อจาก Ex 3)

ข้อ ก)

โอกาสที่โครงการนี้จะเสร็จได้ภายใน 42 วัน ($T_s = 42$)?

$$Z = \frac{T_s - T_e}{\sigma_{Te}}$$
$$Z = \frac{42 - 45.83}{1.66} = \frac{-3.83}{1.66} = -2.31$$
เปิดตาราง Z Table ที่ $Z = -2.31$
พื้นที่ใต้กราฟ $= 0.0104 \rightarrow 1.04\%$

สรุป: มีโอกาสที่จะทำงานให้เสร็จได้ภายใน 42 วันเพียง 1.04% เท่านั้น (แทบเป็นไปไม่ได้)

ข้อ ข)

จำนวนวันที่จะทำให้โครงการเสร็จ โดยมีโอกาสเสร็จถึง 90% ($P = 0.90$)?

เปิดตาราง Z Table หาพื้นที่ $0.9000 \rightarrow$ ได้ค่า $Z \approx 1.28$
$$Z = \frac{T_s - T_e}{\sigma_{Te}} \implies 1.28 = \frac{T_s - 45.83}{1.66}$$
$$T_s = (1.28 \times 1.66) + 45.83 = 2.12 + 45.83$$
$$T_s = 47.95 \approx 48 \text{ วัน}$$

สรุป: หากต้องการความมั่นใจสูงถึง 90% ว่าโครงการจะเสร็จทัน ต้องกำหนดระยะเวลา 48 วัน
